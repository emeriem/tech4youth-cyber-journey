# Commands

- [`commands.sh`](commands.sh) — the complete ordered command reference for this task,
  with comments. **This is a reference file, not a script meant to be run start-to-finish
  in one shot** — several sections require switching users (`su -`) or entering a
  password interactively, which cannot run unattended. Follow it top to bottom manually,
  or use `scripts/setup.sh` and `scripts/verify.sh` for the two pieces that are safe
  to automate (see `scripts/README.md`).
